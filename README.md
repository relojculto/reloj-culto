# Reloj del culto

Reloj de cuenta regresiva para las partes del culto. Se instala en Android y iPhone.

## Instalar
- **Android (Chrome):** abre el enlace → menú ⋮ → *Instalar app*.
- **iPhone (Safari):** abre el enlace → Compartir → *Agregar a pantalla de inicio*.

## Actualizar
Reemplaza `index.html` en el repositorio. Si el celular no muestra el cambio, cierra la app y ábrela de nuevo.
